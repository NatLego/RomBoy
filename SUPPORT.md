# Support and feedback

[Back to RomBoy](README.md)

## Report a problem

[Open a bug report](https://github.com/NatLego/RomBoy/issues/new?template=bug_report.yml) and include:

- Your RomBoy version, phone model and Android version.
- What you were doing, what you expected and what happened instead.
- How to make the problem happen again, if you know.
- Your controller model, if relevant.
- Your RomM version, if the problem involves a server connection or backup.

Screenshots can help. Remove passwords, access tokens, pairing codes, server addresses and personal information before posting. The issue tracker is public. Do not upload ROMs, BIOS files or private save files.

## Suggest a feature

[Open a feature request](https://github.com/NatLego/RomBoy/issues/new?template=feature_request.yml). Explain what you want to do and how it would help. Check the [roadmap](ROADMAP.md) and existing issues first. If someone has already asked for the same thing, add your feedback there.

## Ask a question

Use [Discussions](https://github.com/NatLego/RomBoy/discussions) for setup questions, compatibility questions and general conversation. Include your app version and device details where relevant.

This page is for help with RomBoy, an independently developed app. For problems with RomM itself or your controller hardware, contact the relevant project or manufacturer.
