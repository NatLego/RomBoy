# Support and feedback

[Back to RomBoy](README.md)

## Report a problem

[Open a bug report](https://github.com/NatLego/RomBoy/issues/new?template=bug_report.yml) and include:

- Your RomBoy version, phone model and Android version.
- What you were doing, what you expected and what happened instead.
- Steps that reproduce the problem.
- Your controller model, if relevant.
- Your RomM version, if the problem involves a server connection or backup.

Screenshots can help. Remove passwords, access tokens, pairing codes, server addresses and personal information before posting. The issue tracker is public. Do not upload ROMs, BIOS files or private save files.

## Suggest a feature

[Open a feature request](https://github.com/NatLego/RomBoy/issues/new?template=feature_request.yml). Explain what you want to do and how it would help. Check the [roadmap](ROADMAP.md) and existing issues first so related feedback stays together.

## Ask a question

Use the [issue tracker](https://github.com/NatLego/RomBoy/issues) for a setup or compatibility question. Include your app version and device details where relevant.

RomBoy is independently developed. Report problems with RomBoy here; this repository is not a support channel for the RomM project or emulator hardware manufacturers.
