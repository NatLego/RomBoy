# Roadmap

[Back to RomBoy](README.md)

Updated 14 September 2026. These statuses distinguish the current development build from future plans. Public availability is announced separately.

## In the current build

- Built-in Game Boy, Game Boy Color and Game Boy Advance emulation.
- Local ROM imports and offline play.
- Optional connection to a compatible RomM server, library browsing and selected downloads.
- Download progress with pause, resume and retry controls.
- Local saves, supported server backups and restores, save import/export and conflict choices.
- Removing downloaded games while keeping saves.
- Touchscreen and compatible controller support.
- Customisable gameplay skins, dark mode and a screenshot album.
